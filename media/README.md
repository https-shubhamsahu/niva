# Shared media

The visual material for all three Niva projects (startup, Aavishkar and SIH) lives here. Never delete anything in this folder. If a project needs a resized copy, make one inside that project and keep the original here.

| Folder | Contents |
|---|---|
| `photos/` | Original real photos: `1.jpg` prototype, `2.jpg` Automation Expo 2026 with visitors, `3.jpg` team at the expo, `4.webp` concept image of footwear (Astra) |
| `brand/` | Niva logo lockups (`niva_logo_assets/`) |
| `cad/` | Engineering brief and outputs: the 3D engineering prototype (Blender file, renders, PCB renders), vector blueprints (Rev A), design notes, concept images |
| `app-graphics/` | App and dashboard graphics: architecture diagram, foot map, logo |
| `video/` | Video scripts: the Niva showcase script, and the SIH26004 video script and transcript |

Label what each image is when you use it:
- **real photo** for the prototype and expo photos;
- **CAD render** for renders;
- **concept image** for generated or concept art.

Copies that builds depend on stay with their project:
- the SIH deck kit's `assets/`;
- the app's `assets/`;
- the dashboard's `public/`.
