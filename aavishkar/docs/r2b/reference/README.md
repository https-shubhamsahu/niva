# Reference values for the R2b consistency checks

Both files hold results for participants 002 to 013 only. They were computed on 21 November 2026,
after the v1 outcomes were known and before the R2b plan was written.

- `sens147_first12.json`: the v1 outcomes recomputed with 14.7 mm discs.
- `posthoc_first12.json`: scale descriptors (mean loaded contact area per stance sample, bounding-box
  length and width, total disc area).

The R2b run stops unless it reproduces these values and the stored v1 step records.
