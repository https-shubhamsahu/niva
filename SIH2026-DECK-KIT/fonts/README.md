# Bundled fonts (all SIL Open Font License 1.1)

These let the deck render with the same layout on machines without Microsoft fonts, such as Linux cloud containers. On Windows, `fonts.css` uses the installed fonts first, so these files are only a fallback.

| Stands in for | Bundled font | Licence file |
|---|---|---|
| Arial | Arimo | LICENSE-arimo.txt |
| Segoe UI | Selawik (Microsoft) | LICENSE-selawik.txt |
| Calibri | Carlito | LICENSE-carlito.txt |
| Times New Roman | Tinos | LICENSE-tinos.txt |
| Garamond | EB Garamond | LICENSE-ebgaramond.txt |
| Bahnschrift | Barlow Semi Condensed | LICENSE-barlowsemicondensed.txt |
| Nirmala UI (Devanagari) | Noto Sans Devanagari | LICENSE-notosansdevanagari.txt |
